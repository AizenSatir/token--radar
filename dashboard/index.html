How it is scored

Every number on this board comes from one sealed snapshot of the protocol universe (DefiLlama, 2026-11-14). Nothing is typed in by hand and no protocol name is ever special-cased: the same function scores every row.

Implied value = TVL × category multiple × size factor × growth × maturity.

  • Category multiple — the median market-cap-to-TVL of the tokenised protocols in the same category, in this same snapshot. A category with fewer than 3 tokenised peers falls back to the whole-market median (0.21). Multiples are clamped to 0.05–1.00, so no single outlier sets the price.
  • Size factor — (100M / TVL)^0.12, clamped to 0.6–1.4. A big pool's token is worth less per TVL dollar than a small one's.
  • Growth — the 7-day TVL change, clamped to −30…+60%, at half weight.
  • Maturity — 0.65 + 0.35 × ln(1 + age) / ln(1 + 1095 days). A protocol that has run longer with no token is nearer a launch; unknown age counts as 365 days.

What counts as pre-token. A protocol records no token when its DefiLlama record carries no market cap, no CoinGecko id and no symbol. That is the record, never proof: a protocol on this board may still have a token its record does not carry. Wrapped, staked and bridged products of a token that already trades are set aside by the same rule the watchlist uses, so they never rank as pre-token.

Farm plans. Each plan is generated from the protocol's own record — its category, its chains, its TVL and its age. Every step states what it costs and how long it takes. An implied value is this entry's claim about what a token would be worth if the protocol's record stayed as it is. It does not predict whether or when a token is issued.
